## Make a mod

Mods change how a town looks, what villagers say, what shops sell, which days are special, and with a small Lua script, what happens when you play.

- [**playac-mods**](https://github.com/Play-AC-Online/playac-mods): the mod API, starter kits, the `playac-mod` command-line tool and the setup guides.
- [**Developer docs**](https://playaconline.com/modding/): guides, the API reference, a cookbook and every error code.

## Example mods

Each example is a whole mod in its own repository, laid out the way yours will be, and each puts two kinds of mod together. Fork one to start.

| Example | What it shows |
|---|---|
| [Springtime Town](https://github.com/Play-AC-Online/playac-example-springtime-town) | New textures and new villager lines, no code |
| [After Hours](https://github.com/Play-AC-Online/playac-example-after-hours) | Nook's from 1 AM to 3 AM, selling only gyroids, a different few each night, and now and then a lantern with its own pictures |
| [Harvest Post](https://github.com/Play-AC-Online/playac-example-harvest-post) | Calendar days and letters, and a script with commands and a timer |

## Rules

Mods on the mod list are reviewed before anyone can install them. Read the [mod rules](https://playaconline.com/wiki/mod-rules/) before you publish one.
